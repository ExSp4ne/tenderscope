# TenderScope - frontend

Веб-интерфейс аудита государственных закупок: вводишь номер закупки или загружаешь контракт - получаешь «светофор рисков» с разбором опасных пунктов по 44-ФЗ и 223-ФЗ.

## Стек

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- lucide-react (иконки)

## Быстрый старт

```bash
npm install
npm run dev
```

Открыть http://localhost:5173.

## Скрипты

| Команда         | Описание                              |
| --------------- | ------------------------------------- |
| `npm run dev`   | Dev-сервер с HMR (http://localhost:5173) |
| `npm run build` | Проверка типов (tsc) + прод-сборка    |
| `npm run lint`  | Линтер (oxlint)                       |
| `npm run preview` | Локальный просмотр прод-сборки      |

## Экраны

### Стартовый экран (`src/components/StartScreen.tsx`)

- Ввод номера закупки с валидацией (11 или 19 цифр) и кнопкой «Проверить контракт»
- Зона drag-and-drop для файлов контракта (`.pdf`, `.docx`)
- Кнопка демо-разбора «Демо: Контракт с отсрочкой 60 дней»

### Светофор рисков (`src/components/AuditDashboard.tsx`)

- Шапка: номер закупки, заказчик, начальная цена, закон, статус, общий вердикт
- Три цветных счётчика: красные (критические), жёлтые (предупреждения), зелёные (безопасно)
- Фильтры: «Все», «Только красные», «Жёлтые», «Зелёные» (счётчики тоже кликабельны)
- Карточка риска: цветная плашка уровня, бейдж категории, заголовок, суть опасности, рекомендация и цитата из документа со ссылкой на страницу и пункт

## Структура

```
src/
├── components/
│   ├── StartScreen.tsx      # стартовый экран
│   └── AuditDashboard.tsx   # экран «светофор рисков»
├── mocks/
│   └── audit_mock.json      # тестовый результат аудита
├── types/
│   └── audit.ts             # RiskItem, AuditResult и служебные типы
├── App.tsx                  # переключение экранов
├── main.tsx
└── index.css                # Tailwind
```

## Данные и подключение бэкенда

Типы доменной модели:

- `RiskItem` - риск: `id`, `category`, `level` (`red | yellow | green`), `title`, `description`, `recommendation`, `quote`, `pageNumber`, `clauseNumber`
- `AuditResult` - результат аудита: `tenderNumber`, `title`, `customer`, `price`, `lawType`, `status`, `summary`, `risks`
