# Проверка детектора рисков

Скрипт использует стандартную библиотеку Python и обращается к API Chat
Completions. По умолчанию ожидается запущенная локальная Ollama с моделью
`qwen2.5:7b`. Команды выполняются из каталога `ml/`.

```powershell
ollama pull qwen2.5:7b
python evaluate_sample.py
python evaluate_sample.py --runs 5
```

Для другого сервера укажите полный URL в `RISK_API_URL`, имя модели в
`RISK_MODEL` и при необходимости ключ в `RISK_API_KEY`. Скрипт проверяет
сырой текст ответа через `json.loads`, набор полей, `payment/red` и точное
совпадение цитаты с предложением из контрольного фрагмента. Код выхода
ненулевой при первом несоответствии. Контрольный фрагмент взят из примера
в `docs/contracts.md`.

## Эталонные документы

В `dataset/annotations.json` поле `pending_sources` содержит кандидатов,
для которых еще предстоит скачать или проверить первичный документ.
В `documents` добавляются только проверенные документы с полями `file`,
`law`, `source_url` и `annotations`. Каждая аннотация содержит `page`
(счет с единицы), `clause`, `exact_quote`, `category` и `level`.
Для DOCX сверяйте страницу в зафиксированном PDF-рендере оригинала.
Для контрольного документа без выявленных рисков указывайте пустой
массив `annotations` после проверки всех пяти категорий.
